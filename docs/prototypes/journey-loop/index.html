How the loop works

The journey below is never stored — it's recomputed every time state changes.

State (left) → Engine (a pure function) → Journey (center).

Change a goal, flip an answer, or advance a month and watch items appear/disappear here. No decision tree — just rules over data.

Tasks anchored to a deadline (application plan, a test sitting) re-time themselves. Tasks pinned to an external calendar — FAFSA, AP exams — never move.
